# Tela 01 — Home (endereço legado)

A única implementação da Home é [`../../index.html`](../../index.html).

Este diretório conserva apenas `index.html` como redirecionamento para manter compatibilidade com links antigos. **Não copie a página nem crie CSS ou JavaScript próprios aqui.**

Para editar a Home:
- Estrutura e conteúdo: `../../index.html`
- Estilos: `../../assets/css/hub.css` (e estilos comuns em `../../assets/css/`)
- Comportamento: `../../assets/js/hub.js` (e utilitários em `../../assets/js/utils.js`)

As páginas internas devem retornar diretamente para `../../index.html`.
